شاشتان تستدعيان الـAPI الحقيقي — بلا تسجيل دخول، ويتحوّلان بالوقت بنقرة.

🖥️ شاشة الموظف

من تجميع الطلبات إلى إغلاق النتائج — بمؤشر يراقب كل مرحلة من أول أمر.

📱 تطبيق الطالب

طلب الشهادة، متابعة الحالة، دفع إعادة الامتحان.

حالة الخادم

التشغيل

  1. شغّل الخادم — npm run start:dev
  2. ابذر الطلاب بلا شهادات — SEED_CERTIFICATES=false npm run seed:dev
  3. افتح الصفحة مباشرةً أو عبر serve:
    npx --yes serve docs/sim-certificates -l 5500

سيناريو كامل في الصور

يغطي الدورة كاملاً من عشر خطوات — والساعة في الأعلى تختصر الأيام.

  1. تطبيق الطالب — اختر «طالب ١» وقدّم طلب شهادة. كرّرها بطالبين أو ثلاثة.
  2. شاشة الموظف — «طلبات بانتظار دورة» — حدّدهم وأنشئ دورة. لاحظ الرقم التسلسلي.
  3. في صفحة الدورة: أدخل الجلسات الثلاث واتركها — إشعار الطلاب يكمل وحده.
  4. عند تطبيق الطالب — الحالة صارت «في التدريب الحكومي» والمواعيد ظاهرة.
  5. الموظف — اضبط موعد الامتحان (بعد ٤ أيام).
  6. اضغط +يوم في الأعلى أربع مرات — صرت في يوم الامتحان بلا انتظار.
  7. الموظف — زر «📝 إدخال نتائج الامتحان» — أرسلها أحدهم ناجح والباقين راسب.
  8. الراسب الآن مؤهل للإعادة: افتح تطبيق الطالب بهويّته — ظهر الزر والعدّاد.
  9. أنشئ دورة ثانية واضبط لها موعداً — سيُدرج الراسب تلقائياً.
  10. قدِّم الساعة بعد ليلة التسجيل — اختفى الزر وردّ الخادم «انتهت المهلة».
